🛰️ SatSort

Modern Linux Native SatcoDX (.sdx) Uydu Kanal Listesi Düzenleyici

📦 APT Deposu ile Kurulum (Ubuntu / Debian / Pardus / Mint)

Depoyu sisteminize ekleyerek SatSort'u tek komutla kurabilir ve otomatik güncellemeleri alabilirsiniz: 

# 1. SatSort APT deposunu ekleyin
echo "deb [arch=amd64 trusted=yes] https://gokcank.github.io/SatSort stable main" | sudo tee /etc/apt/sources.list.d/satsort.list

# 2. Paket listesini güncelleyip kurun
sudo apt update
sudo apt install satsort

🚀 Diğer Dağıtım Seçenekleri

Kurulum yapmadan tek tıkla çalıştırmak isterseniz Evrensel AppImage paketini veya taşınabilir ikili dosyayı GitHub üzerinden indirebilirsiniz.
